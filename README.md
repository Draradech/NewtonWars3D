Newton Wars 3D
==========

This is the 3D version of [Newton Wars](https://github.com/Draradech/NewtonWars). In contrast to the 2D version, this has no central display, the rendering is performed on the client, which is made in Godot 4 (using GDScript). The server is written in C (like the original).
